WatchOut — HTML build and GitHub Pages deployment

This branch (`copilot-html`) contains the compiled static HTML version of the project, generated by the GWT compiler. It's intended to be pushed to GitHub and served via GitHub Pages.

How this branch was produced
- Upgraded Gradle wrapper to 4.10.3 locally so it can run on newer hosts when using Java 8.
- Removed the missing legacy Gradle GWT plugin and invoked the GWT compiler directly using `gwt-dev`.
- Staged `core` and `html` sources into a temporary directory and ran `com.google.gwt.dev.Compiler` via a Gradle JavaExec task to produce the static output at `html/build/gwt/out/html`.
- The compiled output was copied into this orphan branch and committed.

Quick build instructions (reproduce locally)
1. Install Java 8 (OpenJDK 8).

   export JAVA_HOME=/usr/lib/jvm/java-8-openjdk-amd64
   export PATH=$JAVA_HOME/bin:$PATH

2. Run the HTML build using the Gradle wrapper:

   ./gradlew :html:compileGwt :html:war --stacktrace

3. The compiled, browser-ready site will be at:

   html/build/gwt/out/html

Publishing to GitHub Pages
- Option A (branch publish): push this `copilot-html` branch to the repository and enable Pages to serve the branch root. Example:

   git push origin copilot-html

  Then in the repo Settings → Pages, select the `copilot-html` branch and root directory.

- Option B (gh-pages): rename branch to `gh-pages` or push to `gh-pages` if you prefer the conventional name.
